01 — Introducción

¿Qué es Amazon EC2?

Amazon Elastic Compute Cloud (EC2) es el servicio de cómputo en la nube de AWS. Te permite rentar servidores virtuales (llamados instancias) para ejecutar tus aplicaciones sin necesidad de administrar hardware físico.

Con EC2 puedes elegir el sistema operativo, la cantidad de CPU, memoria RAM, almacenamiento y configurar la red. Es uno de los servicios más utilizados en la nube y base de muchas arquitecturas modernas.

¿Por qué EC2?

Si necesitas correr un servidor Node.js, una API en Go, o cualquier proceso que requiera cómputo continuo, EC2 es la opción más directa y flexible en AWS.

02 — Conceptos

Conceptos clave

Antes de lanzar una instancia, es importante entender estos términos:

  • AMI (Amazon Machine Image): imagen base del sistema operativo (Ubuntu, Amazon Linux, etc.).
  • Instance type: combinación de CPU, RAM y red (ej. t2.micro, t3.small).
  • Key pair: par de llaves SSH para autenticarte de forma segura.
  • Security Group: firewall virtual que controla el tráfico de entrada y salida.
  • Elastic IP: dirección IP pública estática que puedes asignar a tu instancia.
  • VPC: red virtual privada donde viven tus recursos de AWS.

04 — Práctica

Lanzar una instancia EC2

Sigue estos pasos desde la consola de AWS:

  1. Inicia sesión en console.aws.amazon.com y ve a EC2 → Instances → Launch Instance.
  2. Asigna un nombre descriptivo, por ejemplo: mi-servidor-api.
  3. Selecciona la AMI: Ubuntu Server 22.04 LTS (Free tier eligible).
  4. Elige el tipo de instancia: t2.micro (gratis).
  5. En Key pair, crea uno nuevo y descarga el archivo .pem. Guárdalo en un lugar seguro.
  6. En Network settings, permite tráfico SSH (puerto 22) desde tu IP, y HTTP (80) si necesitas un servidor web.
  7. Deja el almacenamiento en 8 GB (suficiente para empezar) y haz clic en Launch Instance.
⚠ Importante

El archivo .pem solo se puede descargar una vez. Si lo pierdes, no podrás conectarte a la instancia y tendrás que crear un nuevo key pair.

05 — Conexión

Conectarse por SSH

Una vez que la instancia esté en estado Running, puedes conectarte desde tu terminal:

Paso 1 — Ajustar permisos del archivo .pem

Terminal (macOS / Linux)
chmod 400 mi-llave.pem
# Restringe los permisos; SSH rechaza llaves con permisos abiertos

Paso 2 — Conectarse

Terminal
ssh -i mi-llave.pem ubuntu@<IP-PUBLICA>
# Para Ubuntu usa "ubuntu@", para Amazon Linux usa "ec2-user@"
💡 Tip

La IP pública la encuentras en EC2 → Instances → tu instancia → Public IPv4 address.

Paso 3 — Actualizar el sistema

Dentro de la instancia
sudo apt update -y # Actualiza lista de paquetes
sudo apt upgrade -y # Instala actualizaciones
06 — Referencia

Comandos útiles en la instancia

Instalar Node.js

Ubuntu 22.04
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node --version  # Verifica la instalación

Instalar Docker

Ubuntu 22.04
sudo apt install -y docker.io
sudo systemctl enable docker
sudo systemctl start docker
sudo usermod -aG docker ubuntu  # Agrega tu usuario al grupo docker

Monitorear recursos

Comandos de monitoreo
top                  # Uso de CPU y memoria en tiempo real
df -h               # Espacio en disco
free -m             # Memoria RAM disponible
netstat -tlnp       # Puertos en uso
07 — Buenas prácticas

Costos y buenas prácticas

  • Detén las instancias cuando no las uses. Una instancia detenida no cobra por cómputo (sí por almacenamiento).
  • Usa Elastic IP si necesitas una IP fija para tu dominio o DNS.
  • Configura alarmas de billing en CloudWatch para no tener sorpresas en tu factura.
  • Nunca abras el puerto 22 a 0.0.0.0/0 en producción. Restringe SSH solo a tu IP.
  • Haz snapshots de tu volumen EBS periódicamente como respaldo.
💡 Resumen

EC2 es la base del cómputo en AWS. Dominar cómo lanzar, conectar y administrar instancias es fundamental para cualquier arquitectura en la nube.
